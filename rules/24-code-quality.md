# 코드 품질 규칙

## 필수 준수 사항

1. **DRY (Don't Repeat Yourself)**: 중복 코드를 발견하면 함수나 모듈로 추출한다.
2. **단일 책임 원칙**: 함수 하나는 한 가지 일만 한다. 100줄 이상이면 분리를 고려한다.
3. **명시적 타입**: TypeScript/Python 등에서 가능하면 타입을 명시한다.
4. **보안 우선**: 시크릿, API 키, 비밀번호는 절대 하드코딩하지 않는다. 환경 변수를 사용한다.

## 금지 사항

- `console.log`를 디버깅 용도로 남기지 않는다 (프로덕션 코드 기준).
- `any` 타입 남용 금지 (TypeScript).
- `eval()` 사용 금지.
- 사용하지 않는 import/변수를 남기지 않는다.
