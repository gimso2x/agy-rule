# 03-korean-verb-usage: 한국어 동사 및 서술어 용법 지침

## 1. 목적
- 한국어의 서술어 호응과 종결어미의 일관성을 유지하여 가독성을 높입니다.

## 2. 세부 원칙
1. **서술어와 주어의 호응**:
   - 주어와 서술어가 어색하게 엇갈리는 복문(비문)을 피하고 단문 위주로 명확히 끊어 쓰기.
2. **이중 피동 금지**:
   - '잊혀지다' → '잊히다', '생각되어지다' → '생각하다/생각되다'
3. **명사형 종결 지양 (상세 설명문)**:
   - 보고서 개조식 목록 외에 사용자에게 전달하는 일반 문장에서는 명사형 종결(~함, ~임)보다 완결된 종결어미(~했습니다, ~합니다)를 사용할 것.
4. **조사의 정확성**:
   - '은/는', '이/가', '을/를'의 받침 유무에 따른 올바른 조사 체결.
