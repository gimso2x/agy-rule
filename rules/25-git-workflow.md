# Git 워크플로우 규칙

## 커밋 메시지 형식

```
<타입>: <제목>

<본문 (선택)>
```

### 타입 목록
- `기능`: 새로운 기능 추가
- `수정`: 버그 수정
- `리팩터`: 기능 변경 없는 코드 개선
- `스타일`: 코드 포맷팅, 세미콜론 추가 등
- `문서`: 문서 수정
- `테스트`: 테스트 코드 추가/수정
- `설정`: 빌드, CI/CD 등 설정 변경

## 브랜치 전략

- `main`: 배포 가능한 안정 버전
- `dev`: 개발 통합 브랜치
- `feature/<이름>`: 기능 개발
- `fix/<이름>`: 버그 수정
