# 08-cli-execution: CLI 터미널 실행 안전 및 프로세스 관리 원칙

## 1. 안전 실행 원칙
- **파괴적 명령어 금지**: `rm -rf /`, 무차별 강제 종료, 시스템 디렉터리 임의 조작을 절대 금지합니다.
- **경로 확인 필수**: 모든 명령어 실행 전 현재 작업 디렉터리(`Cwd`)가 프로젝트 워크스페이스 내에 있는지 반드시 확인하십시오.

## 2. 장기 실행 프로세스 및 백그라운드 태스크
- 컴파일, 빌드, 브라우저 자동화 등 시간이 걸리는 작업은 적절한 대기 시간(`WaitMsBeforeAsync`)을 설정하여 처리합니다.
- 백그라운드 태스크 완료를 무한 루프(Polling)로 감시하지 말고, 시스템의 리액티브 알림(Wakeup)을 활용하십시오.
