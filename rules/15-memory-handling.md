# 15-memory-handling: 컨텍스트 보존 및 장기 메모리 관리 원칙

## 1. 목적
- 긴 세션 진행 시 발생할 수 있는 컨텍스트 유실 및 정보 왜곡을 방지하고, 중요한 중간 발견과 결정을 영구 보존합니다.

## 2. 메모리 저장소 운용
- 프로젝트 핵심 규칙 및 사용자 특화 지침은 `.harness/memory/`에 기록합니다.
- 복잡한 리서치 결과나 환경 진단 내역은 전역 `~/agentic/.harness/audits/`에 보관하여 차후 세션에서 즉시 재활용할 수 있게 합니다.
- 임시 작업 스크립트는 프로젝트 루트를 어지럽히지 말고 전용 `scratch/` 디렉터리에 격리하여 작성합니다.

## 3. 컴팩션 신뢰와 긴 세션
- 컨텍스트가 길어졌다는 이유만으로 작업을 멈추거나 새 세션으로 넘기라고 권하지 않습니다. 런타임 컴팩션을 믿고 같은 세션에서 끝까지 진행합니다.
- 대신 컴팩션 뒤에도 이어 갈 수 있도록 중간 결과(계획, 결정, 검증 증거)를 `.harness/` 파일로 저장하고, 검증된 단계마다 커밋합니다.
- `handoff/` 문서는 사용자가 세션을 끝내거나 다른 에이전트에게 넘길 때만 작성합니다.
